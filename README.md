## 🎯 Objetivo del Sitio
Diseñar y desarrollar un sitio web informativo y estático utilizando exclusivamente HTML5 y CSS3, optimizado para su despliegue en Microsoft Azure Static Web Apps, cumpliendo con los estándares de diseño responsive, semántica web y accesibilidad.

## 🛠️ Tecnologías Utilizadas
* *HTML5:* Estructuración semántica de las páginas (Inicio, Nosotros, Productos, Contacto).
* *CSS3:* Diseño visual, maquetación con Flexbox/Grid, sombras, bordes, pseudoclases y adaptabilidad con media queries.
* *Control de versiones:* Git y GitHub.
* *Hosting:* Azure Static Web Apps.
